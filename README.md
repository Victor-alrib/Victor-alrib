## Olá, eu sou o Victor

Estudante de **Engenharia de Controle e Automação (IFSP)**, focado em **IA aplicada a dados industriais**: manutenção preditiva, séries temporais e validação rigorosa de modelos.

Minha base é automação e controle. Nos projetos abaixo, uso essa base para resolver problemas de dados com o rigor de engenharia: testes automatizados, resultados reproduzíveis e nenhuma métrica que não tenha sido medida.

### Projetos

| Projeto | O que faz | Stack |
|---|---|---|
| [**PredictLab**](https://github.com/Victor-alrib/predictlab) | Plataforma de manutenção preditiva: importa históricos de sensores, calcula MTBF/MTTR/disponibilidade, detecta anomalias e treina modelos que antecipam falhas, com validação temporal e avaliação por evento. | Python · FastAPI · scikit-learn · XGBoost · statsmodels · React |
| [**ML Lab**](https://github.com/Victor-alrib/ml-lab) | Laboratório para treinar, avaliar e comparar modelos em dados industriais, com pré-processamento sem vazamento, baseline obrigatório e teste estatístico entre modelos. | Python · FastAPI · scikit-learn · XGBoost · React · Docker |
| [**ControlLab**](https://github.com/Victor-alrib/controllab) | Laboratório virtual de controle (P/PI/PID) com simulação numérica verificada contra soluções analíticas por 25 testes automatizados. | Python · NumPy · SciPy · python-control · React |
| [**SQL Industrial Trainer**](https://github.com/Victor-alrib/sql-industrial-trainer) · [demo](https://victor-alrib.github.io/sql-industrial-trainer/) | 47 exercícios de SQL com problemas de manutenção industrial, SQLite no navegador e correção automática pelo resultado da consulta. | TypeScript · React · sql.js · Vitest |
| [**Portfolio Manager**](https://github.com/Victor-alrib/portfolio-manager) · [demo](https://victor-alrib.github.io/portfolio-manager/) | App para organizar projetos de portfólio, competências e preparação para vagas, com uma regra que impede métricas inventadas. | TypeScript · React · Zustand |
